x402 Preflight

Check an x402 endpoint before you pay it.

Catalogues now list hundreds of paid x402 endpoints. The advertised price, settlement network and recipient wallet are not always what the endpoint actually asks for once you call it, and some do not answer at all. There is exactly one way to find out without spending: send an unpaid request and read the 402 challenge it returns.

That is all this service does, and it does it carefully.

Live endpoint

Discovery: /.well-known/x402-preflight.json
The paid endpoint runs behind a rotating host. Read the discovery document above for the current base URL rather than hard-coding one — it is updated automatically whenever the address changes.

What you get

FieldMeaning
verdictsafe_to_attempt, pay_with_caution, do_not_pay, unreachable
challengeparsed 402: schemes, networks, recipients, amounts, asset, timeout
findingseach blocking or warning issue, with a reason you can act on
latency_msmeasured on the probe itself

Checks it performs

  • Endpoint answers 402 at all — a paid resource that returns 200 unpaid is not selling what the catalogue says.
  • Recipient address is well-formed for the network it claims (EVM or base58 Solana).
  • Amount is an integer in base units — a decimal here means clients will misprice the call.
  • Multiple recipients in one challenge, which deserve a second look before paying.
  • Optional: recipient, network and price ceiling match what you expected. A mismatch is reported as blocking.

Example

POST /preflight
{
  "url": "https://some-api.example/paid",
  "expect": { "pay_to": "0x…", "network": "base", "max_amount": "50000" }
}
{
  "verdict": "pay_with_caution",
  "http_status": 402,
  "latency_ms": 616,
  "challenge": {
    "speaks_x402": true,
    "networks": ["base", "solana"],
    "pay_to": ["0x52Ab…6C06", "3nmeVj…rSgw"],
    "amounts": ["50000", "50000"]
  },
  "findings": [
    { "level": "warning", "code": "payto_multiple",
      "detail": "Challenge offers several different recipients. Verify which one you are paying." },
    { "level": "ok", "code": "price_within_ceiling", "detail": "Price is within your ceiling." }
  ]
}

Price

0.004 USDC per call, settled on Base. Free: /health and /schema.

What it does not claim

This is an unpaid probe. It reports what an endpoint advertises before payment. It does not prove the endpoint returns a useful response after you pay, and it says so in every response. Targets must be public http(s); private and loopback addresses are refused, so it cannot be used to scan someone's internal network.
